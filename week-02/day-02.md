# Week 02 Day 02 — Instalasi & Dasar Git/GitHub

**Status:** 🟢 Completed  
**Study Time:** 2 jam  
**Environment:** Windows PowerShell

## Objective

Membangun workflow version control untuk menyimpan, melacak, dan mendokumentasikan project Data Analyst secara profesional.

## Git vs GitHub

| Tool | Fungsi |
|---|---|
| Git | Version control yang berjalan secara lokal |
| GitHub | Platform online untuk menyimpan dan membagikan repository Git |

## Core Workflow

```text
Working Directory
      ↓ git add
Staging Area
      ↓ git commit
Local Repository
      ↓ git push
GitHub
```

Workflow praktik:

**Edit → Status → Add → Commit → Push → Verify**

## Repository

`EgiKurnianto/data-analyst-bootcamp`

Git berhasil diverifikasi dengan:

```powershell
git version 2.43.0.windows.1
```

Repository berhasil di-clone dan perubahan berhasil di-stage, commit, push, lalu diverifikasi di branch `main`.

## Portfolio Relevance

GitHub digunakan untuk menyimpan:
- SQL queries
- dataset/data dictionary
- dokumentasi cleaning
- analysis notebook
- dashboard documentation
- README
- insight & recommendation
- changelog

Tujuannya agar portfolio menunjukkan **proses yang reproducible**, bukan hanya hasil akhir.

## Professional Habit

**Document → Track → Review → Improve**

Setiap perubahan sebaiknya dapat dijelaskan: apa yang berubah, mengapa berubah, kapan berubah, dan apa dampaknya.

## Reflection

Version control bukan hanya skill coding. Untuk Data Analyst, Git membantu membangun kebiasaan dokumentasi, reproducibility, dan pengelolaan portfolio yang lebih profesional.
