## Core Analytical Workflow

**Business Problem → Business Question → Data → Analysis → Information → Insight → Recommendation**

Untuk analisis lanjutan: **Data → Metric → Pattern → Insight → Recommendation**

## Kompetensi yang Sudah Dibangun

### Week 01
- Data Analyst role, analytical workflow, dataset literacy, data types, data quality, business questions, percentage change, conversion rate, Information vs Insight.

### Week 02

- COUNT(), SUM(), AVG(), MIN(), MAX()
- Revenue, unit sales, contribution, AOV

- Fact vs hypothesis vs causal claim

## Prinsip Belajar
1. Mulai dari business problem, bukan tools.
2. Pilih data berdasarkan business question.
3. Bedakan fakta, information, insight, hipotesis, dan causal claim.
4. Dokumentasikan reasoning, bukan hanya hasil akhir.
5. Gunakan target minimal 80% mastery sebagai gate.
6. Jangan menyatakan penyebab tanpa evidence yang cukup.
