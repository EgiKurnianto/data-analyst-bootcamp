## Perlindungan file/link
- Sinkronkan remote; periksa git status dan git diff.
- Buat commit kecil dengan pesan jelas; hindari git push --force.
- Gunakan branch untuk perubahan besar.
- Gunakan git mv saat memindahkan file, perbaiki referensi dalam commit yang sama.
- Cari tautan masuk/keluar dan verifikasi setelah perubahan.
- Periksa data sensitif sebelum commit; Git bukan pengganti backup.
